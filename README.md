# 页棱镜 PagePrism

把喜欢的网页，讲清楚。将公开网址转成可核对的设计观察、原站片段、术语解释，以及给 Coding Agent 的任务说明。

**当前状态：可在本机运行的 MVP（2026-10-23）。** 已实现真实浏览器采集与完整交接流程；分析采用有限规则和模板，不调用大模型。未公开部署，也未验证减少 token 或返工的效果。

## 为什么做

学习 Web 开发的人能辨认自己喜欢的布局与动画，却不一定知道如何向 Agent 说明触发动作、变化过程和结束状态。PagePrism 让原站画面与解释对应，让用户先确认想要的效果，再把自己的用途与改造要求交给 Agent。

产品面向学生与初学创作者。能否减少沟通、返工和模型开销，仍需通过真实用户任务验证。

## 现在可以做什么

1. **输入一个公开 HTTP／HTTPS 网址**，读取单页结构、字体、颜色和布局。
2. **查看真实原站截图和录像**：观察最多 3 个悬停目标和有限滚动位置，给出最多 6 个代表条目，记录条件与限制。
3. **在报告里查术语**：点击原地弹出的定义，也可以按中文、英文、别名和白话搜索。现有 46 个详细词条草案，加 3 个项目扩写，共 49 条；来源目录里的主题数量不等于详细词条数量。
4. **单选、多选或全选条目**，用自己的话补充描述；测量值保留不变。
5. **先填写网站用途**，再调整区域、配色、节奏、内容与技术栈。
6. **复制或下载交接材料**：`AGENT-BRIEF.md`、`DESIGN.md`、`evidence.json`；动效关键帧可以导出 4／6／9 格 PNG。

选择与定制内容按每次拆解保存在当前浏览器，结果和媒体保存在本机。内置「原创示例」也会经过同一个真实采集引擎；不会返回词典里的虚构观察样例。

## 运行

需要 **Node.js 22.12+**（或满足 Vite 要求的更新版本）、npm，以及安装 Playwright 浏览器所需的网络。

在本目录运行：

```sh
npm install
npx playwright install chromium
npm run dev
```

打开 **http://127.0.0.1:5173/**。首次可以点击「体验示例」，待真实采集完成后选择效果、查词并生成说明。分析 API 默认在 `127.0.0.1:4317`。

本地生产构建：

```sh
npm run build
npm start
```

打开 **http://127.0.0.1:4317/**。两个启动方式不要同时占用同一个 API 端口。停止运行使用所在终端的 Ctrl+C。

### 数据位置

- 采集结果：`.pageprism/runs/<任务ID>/`，包括报告 JSON、PNG 和 WebM，已被 Git 忽略。
- 用户选择和表单：浏览器 `localStorage`，按任务 ID 区分。
- 可用 `PAGEPRISM_DATA_DIR` 指定采集数据文件夹；默认无自动清理。
- 无模型密钥、云存储或账号配置。除访问目标网页和其公开资源外，不向模型服务上传采集内容。

## 技术结构

```text
公开 URL → 目标检查 → Playwright 受控观察 → 页面事实与实际媒体
                                           ↓
                                  规则归纳与词典关联
                                           ↓
                          React 工作台 → 用户选择与用途 → 交接导出
```

| 层 | 技术与职责 |
| --- | --- |
| 工作台 | React、TypeScript、Vite；报告、播放器、词典、配置与导出。 |
| 本地 API | Express、Zod；任务、取消、并发和媒体白名单。 |
| 观察 | Playwright Chromium；新建无登录上下文，读取、滚动和移动指针。 |
| 归纳与内容 | 页面数据、保守规则、模板和已有 JSON 词典。 |
| 保存与验证 | 本地文件；Vitest 单元／集成测试与 Playwright E2E。 |

客户端兼容检查与采集引擎是两件事：用户可以在不同浏览器打开工作台；当前采集始终由后端 Chromium 执行。WebKit 自动化不等于真实 Safari／iOS 验证。

## 可靠性与边界

- **观察**：截图、前后样式、实际采样时间等可核对信息。
- **候选**：例如滚动期间透明度变化，可能是进入视口触发，也可能是其他时序变化；不直接认定视差或滚动联动。
- **建议**：如何重现类似行为；不能当作原站源码或实际使用的动画库。
- **用户要求**：用途、配色与节奏独立于原站测量值；网页文本作为材料引用，不作为执行指令。

每次最多分析一个任务，总期限 90 秒。失败、取消和部分结果会明确显示，已采集的观察尽量保留。不会承诺找到一个网页的所有精彩部分。

关键帧标注动作采样的实际时间，**不是视频编码时间戳**。视频片段定位按录制页创建时刻估算，可能有少量启动偏差；可以手动播放并结合关键帧核对。移动端只采集窄视口截图，录像仍为桌面视口。

当前不支持登录页、验证码绕过、浏览器会话导入、多页爬取、点击菜单与提交表单、Canvas／3D 语义分析、完整源码复原、自动搭建目标网站或 AI 智能拆解。复杂网站、延迟加载、反自动化和编码差异可能导致观察不完整。

这是**本机开发工具**。已有协议／地址检查、逐请求目标检查、写请求／弹窗／WebSocket 阻断和本地接口来源约束；这些不是生产级网络隔离，不适合直接暴露成公网采集服务。公开部署前需要额外的网络沙箱、资源配额与数据管理设计。

npm run test:integration
