## 核心组织方式

**通用词条 → 可组合的交互配方 → 有原站证据的观察记录 → 用户选择与改造要求 → Agent 任务说明。**

例如：用户说「卡片一张张浮出来」，可以检索到「进入视口」「交错」「淡入」「位移」，再组合成一条可检查的要求，而不需要先学会专业术语。

原文三大章节保留为**来源视图**；产品另按页面结构、视觉风格、动效、组件、工具交互、数据、AI、状态、设备、质量等领域查找。同一个术语只维护一个定义，通过来源记录连接不同文章。

## 范围与成熟度

- 已阅读：3 个父章节、15 篇正文；另查看了词典总入口。部分父页只有标题。
- 已整理：全部章节的结构映射、代表术语与处理原则；动效及视觉词典的编号条目清单。
- 详细词条是架构样本，未把手册所有表格行逐条扩写成发布级内容。目录数量也不能相加当作独立词条数量。
- JSON 保持内容草案与数据样例的性质；应用仅使用其中的详细词条，虚构观察样例不作为采集结果。
- 保留原文链接并用自己的语言重写解释，未收录原文整段提示词。资源的商业转载、演示素材与批量复用授权尚未确认。

下一步可以先用这些文件评审词典结构；正式扩写内容时，按 catalogue 中的主题逐批补充词条、审核定义和复用权限。
