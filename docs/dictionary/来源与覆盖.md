## 3. 必须分义或关联的概念

| 概念组合 | 处理原则 |
| --- | --- |
| In View／Scroll-linked | 到阈值后播放与进度随滚动变化分别定义。 |
| Focus／Attention | 键盘交互位置与视觉注意力分开。 |
| Active／Pressed／Selected | 当前项、瞬时按下、选中分别记录；CSS 伪类另说明。 |
| Tooltip／Popover／Dropdown | 简短提示、可交互浮层、展开菜单或选择内容按语义拆分。 |
| Skeleton／Shimmer／Spinner | 占位结构、扫光动画、不定进度指示不同。 |
| Reading／Upload Progress | 视觉组件相似，但绑定的数据与验收不同。 |
| Infinite Scroll／Marquee | 加载更多数据与循环移动已有内容不同。 |
| Sticky／Scroll Animation | 固定定位本身不代表存在滚动驱动动画。 |
| Shared Element／View Transitions | 前者是效果目标，后者是可选实现能力。 |
| Masonry／CSS Grid | 前者是视觉排列，后者是技术；不能从外观确定源码。 |
| Typewriter／AI Streaming | 预设文字逐字展示与真实增量输出分别定义。 |
| Dark Mode／Color Inversion | 深色主题涉及层级与资源表现，不能只反转颜色。 |
