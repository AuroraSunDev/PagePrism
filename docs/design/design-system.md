# 视觉基线与实现清单

日期：2026-10-23。使用内置 Image Gen 生成四张独立概念：start-concept.png、report-concept.png、brief-concept.png、mobile-concept.png。它们作为本轮直接搭建授权下的视觉基线，不宣称用户逐张批准。

## Tokens

- Canvas #ffffff；rail／document #f5f7fa；text #17212b；muted #66738a；border #e4e9ef；accent #315be8；selected #edf2ff。
- 系统中文无衬线／Inter 风格拉丁后备，文档预览用等宽字体；正文 16px、控件 14px、标题 28—48px，行高 1.5—1.75。
- 间距 4／8／12／16／24／32／48／64；按钮和输入圆角 6—8px；媒体圆角 4px。
- 线性图标，1.8px 左右 stroke，常规 18—20px；不混用装饰性填充图标。

## 页面与组件

- Header 高 72px：品牌、拆解工作台、词典、当前页需要的主要动作。
- Start：最大宽 1120px；标题、输入与主操作、横向示例、最近结果。
- Report：来源条、220—240px 观察列表、约400px说明、可伸缩媒体；底部选择栏。可在中等屏幕将说明与媒体分配约45／55。
- Brief：左侧用途优先表单，右侧 Markdown 预览；复制与下载紧邻预览。
- Mobile：紧凑 Header、可横向浏览条目、说明／原站画面切换、底部选择与继续；词典对话区域可滚动。
- Dictionary：沿用相同 Header、输入、行列表和定义排版，不新增另一套视觉语言。

## 文案基线

品牌：页棱镜 PagePrism。导航：拆解工作台、词典。开始：把喜欢的网页，讲清楚。副文：输入网址，观察设计与动效，整理成给 Agent 的实现说明。操作：开始拆解、体验示例、新建拆解、定制并生成、返回报告、复制、下载 Markdown。

报告静态标签：观察条目、原站片段、关键帧、触发方式、变化过程、实现建议、已观察、原站使用的动画库尚未确认、已选择。其他标题、数量、来源、时间和描述必须来自实际数据。

定制：让参考，成为你的方案。你想用网站做什么？放在哪个区域？强调色、动效节奏、轻快／适中／舒缓、文字与素材、现有技术栈（可选）、Agent 任务说明、任务说明／设计观察／证据 JSON。

## 资产与有意适配

- 概念图里的原站页面为虚构设计参考，生产 UI 不使用整张概念图冒充媒体。内置参考页用原创代码和独立生成的建筑图像构建，再经真实采集生成视频与截图。
- 品牌统一采用报告概念的文字标识；其他概念自行生成的几何标志不作为强制资产，避免四张图标志不一致。
- 报告中的实际条目、时长、画面比例和警告以采集结果为准。不会为匹配概念固定“2项”“4秒”等虚构值。
- 手机概念显示说明与小媒体同时出现；实际窄屏优先遵循 scope 的说明／画面切换，减轻纵向拥挤。
- 视频使用原生可访问控件而非伪造播放器；其平台外观差异属于必要适配。
- 原站媒体按实际比例 contain，避免概念中封面式裁切导致证据丢失。

## 验证

实现时逐屏对照；交付前用 view_image 检查概念与最新截图，记录布局、文案、色彩、文字、间距、媒体及响应式差异。设计文件不是功能通过证据。
