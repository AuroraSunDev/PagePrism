## 测试发现并修复

1. **浏览器函数序列化**：开发运行器插入的名称辅助函数不在目标页中。E2E 暴露错误后，将页面收集器改成独立浏览器脚本文本。
2. **媒体路径**：框架默认忽略隐藏目录，导致已保存媒体返回 400。用隐藏目录回归测试复现，再在经过 UUID／登记文件名校验的媒体根目录显式允许读取。
3. **WebKit 焦点**：点击术语不自动聚焦触发按钮。显式保存触发焦点，关闭弹窗后恢复；WebKit 复测通过。
4. **弹窗首个导航**：新窗口首请求早于 page 事件。请求阶段拒绝非采集页导航，集成测试从 1 次意外请求变为 0。
5. **重定向**：仅依赖浏览器路由不足以覆盖后续跳转。新增每次采集独立的本地出口代理，在连接时验证目标并直接连接已检查 IP；重定向私网测试从错误完成变为拒绝，目标收到 0 次请求。浏览器退出时清理代理连接。
6. **DNS 无响应**：新增 5 秒解析等待上限；假时钟回归由失败变为通过。
7. **术语关联**：普通网格不称为 Bento；未知变换不直接关联滑入，首屏也不直接命名为杂志风。
8. **截图时机**：初次 QA 截图发生在视频定位完成前。最终截图等待解码和定位完成；不将缓冲背景作为媒体完成证据。最后加大报告标题、说明、标签和测量值字号，桌面／窄屏主流程补测 2 / 2。

## 使用与安全边界

- 工作台由 Browser/IAB 先行实际操作；自动化 Playwright 补充多引擎、下载、视频和固定尺寸验证。
- IAB 在开发服务器格式化重启后出现连接失败旧标签；重新打开预览恢复。最终交付保持可用预览。
- 本机服务与出口检查不等于生产网络沙箱。无公网部署、无账号／模型调用／多页爬取；不承诺自动识别所有动效。
- 录制区间可能有启动偏差；关键帧时间是实际动作采样时间，不是编码 PTS。未声称原站使用了建议中的库或实现。
- 原词典 46 条内容草案继续保留；应用额外扩写 3 条定义。第三方内容发布权限仍需确认。

1. 在独立项目文件夹创建本地分支；原目录无 Git 仓库，没有制造远程或假称同步 GitHub。代价是远程集成需要后续明确处理。
2. 依据用户「准备完成后直接搭建」采用本地 MVP 和视觉基线继续执行。代价是后续试用可能调整范围与设计。
3. 关键帧与视频使用不同的实际时间依据，并公开启动偏差。代价是视频可能需要手动微调定位。
4. 在应用适配层增加 3 个原创定义，原词典数据保持不变。代价是发布前需要内容审阅。
5. 使用独立浏览器脚本文本解决运行器序列化问题。代价是该小文件以运行测试校验，不能仅靠 TS 检查。
6. 对通过任务 ID 和登记文件验证的隐藏数据目录允许媒体读取。代价是后续改动必须保留这两道校验。
7. 在浏览器路由之外加入目标验证与 IP 固定连接，修复实际重定向漏检。代价是采集多一个本地代理生命周期；仍不替代部署沙箱。
8. 采集读取 CSS 属性和前后变化，没有实现完整 runtime 动画时间轴。代价是复杂时序与触发关系仍需进一步观察。
