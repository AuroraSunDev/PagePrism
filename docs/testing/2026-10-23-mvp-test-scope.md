## 固定测试材料

原创 reference fixture 是自动化真值：布局、滚动显现、悬停、静态内容、错误／超时等行为由测试控制。内置示例沿相同采集引擎执行；它不能代替外部公开网站的实际检查。

外部公开站点只做有限烟雾检查；网络、反自动化、原站更新会影响结果，不能让不可控网站决定所有单元测试。不得为通过测试绕过登录或挑战。

## 出门条件

1. 类型检查、生产构建、核心单元／集成／E2E 均有当次运行证据。
2. 主流程在真实浏览器使用，媒体播放与图片导出实际检查。
3. 用 view_image 同时检查设计概念与最终截图，记录至少五个具体对照项和合理偏差。
4. 失败或未运行项目分别列出，不把 WebKit 结果称为真实 Safari 测试。
5. README 能使用户启动和重现示例；无密钥、采集私密内容或临时调试产物进入版本记录。
