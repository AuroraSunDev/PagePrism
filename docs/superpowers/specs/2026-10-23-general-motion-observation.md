# 通用视觉观察改进

## 用户确认的目标
提升 URL 拆解的通用识别能力。The Queue 和 Goodgrowth 是缺陷样本，产品代码不匹配其域名、类名、具体文案或特效名称。使用统一的发现、动作、多帧比较和证据归纳流程覆盖其他页面。

## 根因与方案
现有引擎只在加载时寻找少数常规标签；只比较目标本身少量 CSS 属性；依赖文档高度进行瞬时滚动；没有观察自动动画或进入后的状态。改为：
1. 每个可见区域重新发现目标，结合可聚焦元素、可读 CSS 交互规则和指针提示；优先图像／组件，去重重复实例。稳定属性或最近祖先 ID 定位，节点失效不会中断报告。
2. 用同一采样器比较静止、动作中、结束状态。读取目标及子元素、附近新增文字、浏览器动画、可见画布像素；报告实际变化，解释与证据分离。未能证明因果的视觉变化标候选。
3. 发送真实滚轮，观察内部滚动和无普通页面高度的场景。对明确的独立入口层允许最多一次非表单入口按钮点击，随后重新发现和观察；不为某个网站增加动作分支。
4. 沿用现有报告、播放器、词典和导出。最多12条代表观察、8组悬停、120秒；预算和未覆盖范围写入结果。

## 取舍与边界
继续使用本地 Playwright 与规则比较，不新增模型服务。pngjs 只用于真实截图比较。范围是提高可观察变化的覆盖，不承诺自动理解所有 Canvas／3D 语义或复原完整时间轴。画布只在可见且未被入口遮住时比较，像素结论为候选。保持现有出口代理、私网阻断、GET/HEAD限制、取消和媒体保护。入口探索排除表单、登录、注册、订阅、购买、提交、删除和同意条款。

## 验收
使用独立生成的两种结构／标签／文案夹具，覆盖窄小组件、子元素变化、浮出文字、加载动画、动态文字、画布、容器滚动、无文档高度的滚轮场景和安全入口。静态对照不产生动效结论。原站用于额外观察，失败如实记录；不将单站通过当成普适性证明。原闭环和网络防护回归通过。
